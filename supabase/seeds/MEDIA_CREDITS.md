# Seed media credits

The development seed media library (`supabase/seeds/media/`) is uploaded to
the local `media` bucket on `supabase db reset`. Files are named by their
media id; `supabase/seeds/seed.sql` inserts the matching `public.media` rows.
Do not add other files to that directory: every file in it is uploaded.

## Changing the samples

1. Brand images: edit and run `node scripts/generate-seed-media.mjs`, then
   update `size_bytes`, `width`, and `height` in `seed.sql`.
2. Photographs: use only public-domain or CC0 sources whose terms allow
   redistribution in this repository (not Unsplash or Pexels, whose licenses
   forbid redistributing the photos as a collection). Keep files under the
   4 MiB media limit, name them by a new UUID, add the `seed.sql` row, and
   credit them here.
